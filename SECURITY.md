# Security

Report suspected vulnerabilities privately to the repository owner. Do not open
a public issue containing credentials, private data, or exploitable details.

The complete security posture, control inventory, limitations, and reporting
process are maintained in [`aegis/SECURITY.md`](aegis/SECURITY.md).

The agent-identity threat model is in
[`aegis/docs/THREAT_MODEL_AGENT_IDENTITY.md`](aegis/docs/THREAT_MODEL_AGENT_IDENTITY.md).
